منصة تعليمية تفاعلية لحفظ القرآن الكريم بطريقة ممتعة، خاصة للأطفال والمبتدئين.

**🌐 الموقع المباشر:** [https://ahmdschool.github.io/alQuran/](https://ahmdschool.github.io/alQuran/)

---

## ✨ الميزات

- 🎧 **تلاوة صوتية** بصوت الشيخ محمود خليل الحصري (رواية حفص)
- 📖 **قارئ القرآن** (جزء عمَّ حالياً — توسع قريب للقرآن كامل)
- 🔁 **تكرار الآيات** من 1 إلى 10 مرات
- 💡 **تظليل الكلمات** أثناء التلاوة
- 🎯 **3 مستويات اختبارات**:
  - 🧒 المستوى الأول: للأطفال (بصوت الاسم + احتفالات)
  - 📗 اختبار سورة (15 سؤال + مؤقت 30 ثانية)
  - 📚 اختبار شامل (30 سؤال + مؤقت)
- 📋 **خطط حفظ** مخصصة (النور، الفرقان، الإسراء، الحافظ)
- 📊 **تقارير حفظ** قابلة للطباعة والمشاركة (PDF/صورة)
- 🌸 **حديقة الحفاظ** — قصص كرتونية لكل سورة + دروس أخلاقية
- 🌙 **مظهر ليلي ونهاري**
- 🌐 **دعم اللغتين** العربية والإنجليزية
- 💾 **تسجيل بيانات المستخدم** (الاسم + الصورة)
- 📱 **متوافق مع الجوال والكمبيوتر**

- **صدقة جارية** — لكل من يتعلم القرآن

## 🚀 كيفية الاستخدام

1. افتح: [https://ahmdschool.github.io/alQuran/](https://ahmdschool.github.io/alQuran/)
2. اختر السورة
3. اضغط على أي آية لسماعها
4. استخدم زر التكرار لحفظ الآية
5. جرّب الاختبارات التفاعلية
6. سجّل بياناتك واطبع تقريرك
